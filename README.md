# Chat AI — версия для iPhone (PWA)

Это адаптивный сайт, который можно добавить на главный экран iPhone и открывать почти как обычное приложение.

## Запуск локально

1. Установи Node.js 18 или новее.
2. Распакуй архив и открой терминал в папке проекта.
3. Выполни:

   ```bash
   npm install
   npm run dev
   ```

4. Открой адрес, который покажет Vite. Для проверки на iPhone и компьютере в одной Wi‑Fi сети используй локальный IP компьютера и порт Vite.

## Подключение AI

Интерфейс отправляет запросы на `/api/chat` (или на адрес, указанный в настройках). Нужен собственный серверный endpoint, который обращается к выбранному AI API. Не вставляй секретный API-ключ в код сайта или браузер.

Этот архив — фронтенд PWA. Он не обходит ограничения ChatGPT и сам по себе не включает бесплатный доступ к платным моделям.

## Установка на iPhone

1. Размести сайт на HTTPS-хостинге.
2. Открой ссылку сайта в Safari.
3. Нажми «Поделиться» → «На экран Домой».
4. При желании включи «Открывать как веб-приложение» и нажми «Добавить».

Для установки на главный экран нужен опубликованный HTTPS-сайт. Локальный адрес компьютера не подходит для постоянного использования вне домашней сети.
